Who is out there. The game is served from GitHub Pages, which is a static host and never sees a visitor's address — so the counting is done by GoatCounter, which is cookieless, stores no IP and builds no profile of anyone.

What is actually recorded

  • The page that was opened, and where the visitor came from — a link on another site, or nothing at all.
  • Country, worked out at GoatCounter's end from the request. The address itself is never stored.
  • Whether a match was started — the one thing a page view cannot tell you, which is whether anyone got past the title screen.
  • Browser and screen size, which come with any web request.

That is the entire list; it lives in one file, src/core/analytics.js. No cookies, no identifier, nothing that follows anyone between sites. A browser sending Do Not Track or Global Privacy Control is not counted, and neither is the desktop build or a local dev server.

Not counted here?

This is remembered in this browser only (the same switch as ?stats=0 on the game's URL). Clearing site data forgets it.
